# `ui/tauri.conf.json`

[Reference index](../README.md) · [Source](../../../ui/tauri.conf.json)

Names Log Archiver version 0.1.0 and application identifier `com.log-archiver.app`. Serves `frontend`, enables global Tauri bindings, and creates a 1120×760 window with 760×560 minimum. CSP permits local assets, inline styles, data images, and Tauri IPC; bundling is disabled and PNG/ICO paths are configured. Contains no functions.
