# `ui/frontend/styles.css`

[Reference index](../../README.md) · [Source](../../../../ui/frontend/styles.css)

Theme and layout stylesheet with dark tokens and OS-selected light overrides; sidebar/forms/cards; execution steps and progress connectors; results/tables; viewer/preview; activity log; and toast styling. Flow state classes are `active`, `done`, and `error`. Includes a 560px flow-container vertical layout, reduced-motion handling for the active-node pulse, and responsive layout rules. Contains CSS selectors, variables, keyframes, and media/container queries, but no JavaScript functions.
