# `ui/Cargo.toml`

[Reference index](../README.md) · [Source](../../../ui/Cargo.toml)

Desktop package manifest (Rust 2021, version 0.1.0). Links the local core crate, Tauri 2, dialog plugin, SQLite, Serde, directories-next, and notify-rust. `tauri-build` runs at build time; default `custom-protocol` enables embedded frontend serving. Contains no functions.
